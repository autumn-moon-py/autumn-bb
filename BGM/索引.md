# Fog Over Harbor

- **适用场景**：跑团开场，斑木湾的平静清晨，海边日常。
- **核心画面/情绪**：咸湿海风吹过宁静的旅游小镇，阳光穿透薄雾，玩家在安全感中开始探索。
- **风格关键词**：Acoustic, Seaside, Morning, Peaceful, New England
- **节奏建议**：60-70 BPM，动态密度：克制
- **主要音色**：原声吉他 + 轻柔钢琴 + 海鸥/海浪环境音
- **动机钩子**：吉他泛音清脆的滴答声，像晨露滴落。



# Porchlight Rumors

- **适用场景**：与NPC交涉套话，社区闲聊，使用仪态/理性获取情报。
- **核心画面/情绪**：老太太们表面拉家常，暗地摸底细，带着轻微的八卦感与试探。
- **风格关键词**：Pizzicato, Clarinet, Gossipy, Inquisitive, Light suspense
- **节奏建议**：80-90 BPM，动态密度：中等
- **主要音色**：单簧管 + 弦乐拨弦（Pizzicato） + 轻快大提琴
- **动机钩子**：单簧管短促的上升音阶，像挑眉疑问。



# Hearthside Threads

- **适用场景**：触发休闲动作，烛光书店聚会，烘焙园艺，清除状况。
- **核心画面/情绪**：暴风眼中心的绝对安全，壁炉与热茶，恐怖前的极致治愈。
- **风格关键词**：Warm, Hearth, Healing, Acoustic comfort, Safe haven
- **节奏建议**：55-65 BPM，动态密度：克制
- **主要音色**：木管乐器（长笛/双簧管） + 大提琴低语 + 壁炉柴火声
- **动机钩子**：大提琴温暖的长音垫底，像厚重的羊毛毯包裹。



# Dusty Ledger

- **动机钩子**：大键琴断奏，像翻开古老书皮的脆响。



# Casefile on Bourbon Street

# Clockstep Sneak

# Fracture Bloom

- **适用场景**：San Check失败，温馨日常被撕裂，目睹超自然惨状。
- **核心画面/情绪**：安全感瞬间粉碎，认知崩塌，惊恐与恶心。

- **主要音色**：刺耳弦乐群 + 工业金属摩擦 + 突发高频尖啸
- **动机钩子**：一声极度不和谐的钢琴重击，像精神断裂的声音。



# Breakout Pursuit

- **适用场景**：狂放特技/硬汉护体，老太太爆发求生欲，战斗或驾车狂奔。
- **核心画面/情绪**：绝境中的肾上腺素，拐杖挥舞，打破年龄刻板印象的高能时刻。
- **风格关键词**：High energy, Chase, Action, Electric guitar, Unlikely hero
- **节奏建议**：130-145 BPM，动态密度：高能
- **主要音色**：急促打击乐 + 失真电吉他 + 复古追车戏合成器
- **动机钩子**：鼓点密集的过门，像油门踩到底的轰鸣。



# Abyssal Rite

- **适用场景**：接触芳冥助产士线索，发现熟人真面目，感受超自然恶意。
- **核心画面/情绪**：日常背后的冰冷凝视，熟悉的社区与深海邪教交织，令人窒息的压抑。
- **风格关键词**：Drone, Sub-bass, Cult, Underwater, Oppressive dread
- **节奏建议**：40-50 BPM，动态密度：克制（持续压迫）
- **主要音色**：极低频Drone嗡鸣 + 扭曲的女声呢喃（无词） + 水压感环境音
- **动机钩子**：低频嗡鸣中偶尔闪过的微弱水泡碎裂声，像深渊在呼吸。

# Midnight at the Opera House

- **适用场景**：触发“金冠之谜动作”，玩家即兴编造阿曼达·德拉库特的小说情节来寻找灵感。
- **核心画面/情绪**：现实与虚构小说的边界模糊，带有古典推理的华丽感，又透着一丝荒诞的戏剧性。
- **风格关键词**：Baroque pop, Harpsichord, Theatrical, Fiction within fiction, Whimsical
- **节奏建议**：90-100 BPM，动态密度：中等
- **主要音色**：大键琴 + 竖琴滑音 + 夸张的管弦乐拨弦 + 轻微的旧唱片底噪
- **动机钩子**：竖琴快速的刮奏滑音，像翻开小说新篇章的转场音效。



# Fracture Chamber

- **适用场景**：标记虚空之冠（花园阴影/苍白面具等），角色被深渊同化，理智异化。
- **核心画面/情绪**：温馨的日常场景中混入了极度违和的恐怖元素，精神错乱，迷幻且冰冷。
- **风格关键词**：Reverse effects, Dissonance, Psychedelic, Derealization, Unsettling
- **节奏建议**：不规则/自由速度，动态密度：中等（持续不安）
- **主要音色**：倒放的弦乐/钢琴 + 不和谐的钢琴和弦 + 逐渐加速的心跳底噪
- **动机钩子**：音高缓慢下降的倒放钢琴音，像灵魂正在向深渊滑落。



# Iron Fog Harbor

- **适用场景**：查阅斑木湾18/19世纪的捕鲸历史，发现邪教与旧时代的联系。
- **核心画面/情绪**：海兽的悲鸣与人类的贪婪，血腥的航海日志，沉重的历史宿命感。
- **风格关键词**：Sea shanty minor, Foghorn, Maritime gothic, Bleak, Historical
- **节奏建议**：60-70 BPM，动态密度：克制
- **主要音色**：手摇风琴（Hurdy-gurdy）或低音手风琴 + 远处雾号声 + 沉重的铁链拖拽声
- **动机钩子**：手摇风琴持续单调的旋转音型，像无法挣脱的历史轮回。
